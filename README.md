# Tark Android App

The Tark Android App is a next-generation communication client built on the Matrix Rust SDK and optimized for devices running Android 7 and above. Its interface is developed with Jetpack Compose, with navigation powered by Appyx for a smooth and modern user experience.

The Tark Android app integrates the Matrix Rust SDK through a dedicated FFI layer, allowing the client to access its capabilities directly and efficiently. This architecture enables high-performance communication features while ensuring consistent behavior across platforms, making the app both robust and future-ready.

## Status

This project is actively developed and fully supported by the Tark development team. At this time, all development work is handled internally.

## Minimum SDK version

The Tark Android app requires a minimum SDK level of 24 (Android 7.0, Nougat). Our goal is to maintain broad compatibility by supporting devices running Android 7.0 and above, ensuring accessibility across a wide range of actively used hardware.

Tark Android Enterprise requires a minimum SDK level of 33 (Android 13, Tiramisu). For the enterprise edition, we support only devices that continue to receive official security updates, meaning Android 13 and above. This approach ensures a secure, compliant, and enterprise-grade deployment environment.
